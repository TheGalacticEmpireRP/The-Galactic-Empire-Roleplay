THE GALACTIC EMPIRE · OWNER SETUP

Your private staff access code.

This tool creates a random code on your device. It makes no network requests and does not save the code. Keep a private copy for signing in.

  1. Save your generated code privately.
  2. In GitHub, open your repository’s Settings → Secrets and variables → Actions → New repository secret.
  3. Use the name SUPPORT_OWNER_LOGIN_CODE and paste this code as its value.
  4. Run Deploy Imperial Support to Cloudflare on main with project tge-support.
  5. Open https://tge-support.pages.dev/staff. Use the email configured in SUPPORT_OWNER_EMAIL and this access code.
